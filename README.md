# Rifa Nacional Sta. Teresa Mallarauco

App web mobile-first para sortear números de rifa del C.D. Nacional Sta. Teresa Mallarauco.

## Uso

1. Ingresa la cantidad total de números de la rifa (ej: 500).
2. Elige **Número Ganador** o **Número al Agua**.
3. La app sortea un número aleatorio entre 1 y el total ingresado.

## Desarrollo local

Es un sitio estático, solo abre `index.html` en el navegador o sirve la carpeta con cualquier servidor estático:

```bash
npx serve .
```

## Despliegue

Publicado con GitHub Pages desde la rama `main`.
